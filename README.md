# مرصد تقييم المقررات

بوابة مستقلة عن تطبيق القياس والتقويم، مبنية بـReact وVite. صفحتان: المشهد العام واستكشاف النتائج. لا تحتاج API أو تسجيل دخول أو متغيرات بيئة.

## النشر على Vercel

ارفع هذا المجلد وحده إلى مستودع Git ثم استورده في Vercel. إذا رفعت مستودع المشروع الأصلي كاملًا، اجعل **Root Directory** هو `course-evaluation-portal`.

- Framework Preset: **Vite**
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm ci`
- Node.js: **22.x** أو إصدار أحدث يدعمه Vite 8

ملف `vercel.json` موجود. رابط النشر يصدر من Vercel بعد إنشاء المشروع ونشره. تعمل الصفحة الثانية برابط `/#explore` داخل نفس البوابة.

## التشغيل المحلي

```sh
npm ci
npm run dev
```

التحقق: `npm test`، ثم `npm run build`.

## الهيكل الأكاديمي

المسميات المرجعية في `src/academic.js`: خمسة أقسام، وسبعة مسميات درجات علمية كما وردت في قائمة الكلية، وخمسة تخصصات لإدارة الأعمال وأربعة لتكنولوجيا الأعمال. الاقتصاد الرقمي يتبع الاقتصاد، والعلوم السياسية الرقمية تتبع العلوم السياسية. لا يُحوَّل مسمى إدارة الأعمال العام إلى تخصص الإدارة.

المقرر المشترك مرتبط بعدة تصنيفات، لكن ملف التقييم يحتفظ بمعرّف واحد ويُحسب مرة واحدة في الإجمالي. مقارنة الأقسام تسمح بظهوره داخل كل قسم مرتبط به؛ أعداد الأقسام ليست قابلة للجمع للحصول على الإجمالي.

## البيانات والملف الموحد

- `data/evaluations-source.json`: نتائج الاستبانات وربطها بعد مراجعة ملفات CSV.
- `src/courses.json`: البيانات المعدّة للعرض، دون أي اعتماد على ملفات خارج هذا المشروع.
- `public/downloads/college-courses-standardized.xlsx`: قائمة الكلية والهيكل المعتمد والتقييمات بالمسميات الموحدة.
- لتحديث بيانات العرض بعد تعديل المصدر: `npm run prepare:data` ثم `npm run build`.

نتائج التقييم من نسب الأسئلة الرسمية في AN. مؤشر المقرر هو متوسط أسئلته؛ ومؤشر المجموعة متوسط مقرراتها بوزن متساوٍ. لم تُستخدم أعداد الاستجابات لترجيح المؤشرات. التقييمات المعتمدة في النسخة الحالية 225، بعد استبعاد الملفات غير الصالحة والمكررة.

ملف Excel يعرض التصنيف الموحّد لكل صف في قائمة الكلية ويحفظ المسمى الأصلي للتتبع. الرموز الإضافية التي لا تحتوي تصنيفًا موثوقًا تظل غير محددة. لا تُستنتج تخصصات من أسماء المواد وحدها.

## مراجعة دليل الطالب

تمت مراجعة ملف دليل_الطالب__organized.pdf (48 صفحة). يحتوي data/student-guide-index.json على 464 صفًا مستخرجًا من جداول الخطط مع رقم صفحة PDF والصفحة المطبوعة. الفهرس ليس تفريغًا كاملًا لكل خلية؛ عدم وجود مطابقة لا يثبت غياب المقرر. تعرض تفاصيل المقرر حالة المطابقة والأدلة.

المطابقة تعتمد الكود والاسم بعد توحيد علامات الترقيم وصيغ الجمع البسيطة. اختلافات الكود أو الاسم تظل للمراجعة، وقد تكون نتيجة اختلاف اللوائح. لم تتغير الأكواد الأصلية أو نتائج الاستبانات أو فصول طرحها. عضوية المقرر في خطة دراسية لا تثبت هوية الطلاب المستجيبين.

تم ربط MKT403 بالتسويق والذكاء التسويقي، وتصحيح IST306 إلى الاقتصاد الرقمي والعلوم السياسية الرقمية وفق خطتي الدليل مع إبقاء مراجعة مجموعة المستجيبين والفصل. تمت إزالة علامة اختلاف الكود الخاصة بشرطة IST-205 بعد تأكيده في الدليل.

## العرض التحليلي للمؤتمر

أضيفت رسوم مقارنة الفصلين للأقسام، ترتيب محاور التقييم، توزيع النتائج، وخريطة القسم × المحور، مع طباعة التقرير من المشهد العام. المقارنة وصفية ولا تثبت تحسنًا سببيًا، وأولوية المتابعة هي المحور الأقل نسبيًا داخل الاختيار. تظهر الأقسام الخمسة كاملة في رسوم المقارنة والخريطة، وتؤثر الفترة على الخريطة. بقية المؤشرات تتبع الاختيار الحالي. قائمة المقررات مقسمة إلى صفحات من 6 نتائج.

## الفلاتر والتدرج

أزرار الفترة: الكل / الخريف / الربيع. أزرار المجموعة: الكل / Business (إدارة الأعمال والمحاسبة والاقتصاد والعلوم السياسية) / Business Tech (تكنولوجيا الأعمال). التصنيف الرقمي يبقى تحت قسمه الرسمي. يجري تطبيق المجموعة والقسم والتخصص داخل العضوية نفسها لمنع المطابقات المتقاطعة للمقررات المشتركة.

الخريطة تستخدم تدرجًا متصلًا نسبيًا بين أقل وأعلى قيمة ظاهرة وتعرض المدى. اللون الفاتح لا يعني ضعفًا مطلقًا. الأعمدة تعد تقييمات المقررات ضمن فئات 0–70، و70–80، و80–90، و90–100؛ الحد الأعلى مستبعد باستثناء 100. يمكن أن يتكرر نفس كود المقرر في فصلين.


## ترتيب الأقسام ومحاور التقييم

يعرض المشهد العام ترتيب الأقسام حسب متوسط المقررات بعد تطبيق الاختيار الحالي، ويمكن التبديل داخل البطاقة إلى مقارنة الخريف والربيع. ترتيب المحاور من الأعلى للأقل حسب متوسط المحور في المقررات الظاهرة. كل صف يعرض القيمة الفعلية على مقياس 0–100%؛ ترتيب الأقسام لا يجمع نتائج المقررات المشتركة مرتين داخل القسم نفسه.
